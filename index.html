Our Mission Statement

We are Code Niners, a team of UNC Charlotte students learning to design and build software that solves real problems. We value clear communication, shared ownership, and writing code others can understand. Our goal is to deliver a reliable application while growing as engineers and teammates.

Team Rules

  1. Contribute: Everyone will have a role in each assignment to share the work and reduce stress for the whole team.
  2. Stay connected: Communicate with the team through the group chat or by email.
  3. Speak up: Let the team know if you run into any challenges during the project.
  4. Respect each other: Treat every teammate with respect and resolve disagreements instead of holding grudges.
